## github-tutorial
Hello! This is the testing repo for 599 where students will submit their test branch 🚀

My project focuses on developing a system for identifying Garry Oak trees in the area of Greater Victoria using remote sensing imagery.

The remote sensing imagery includes 4-band orthophotgraphy and LiDAR.

This species is at risk and is the keystone species to the Garry oak ecosystem.
